# 阅读图文、接续回复与整理邮件

适用于 dsh-email 0.22.1。入口为 DSH 侧边栏「邮件 → 收发邮件」，中英文文案跟随宿主语言。

## 阅读图文

打开邮件后，工作台保留段落、列表、表格、链接和可识别的内嵌图片；可随时切换纯文本。邮件不会作为网页直接执行：脚本、表单、嵌入页面、事件属性和来源样式不会进入页面。

内嵌 CID 图片从当前邮件附件读取；PNG、JPEG、GIF、WebP 可显示，每张最多 2 MiB。SVG 等格式仍可作为附件下载。损坏或不支持的图片显示失败状态，可重试。图文结构最多处理 256 KiB HTML、32 层、5,000 个节点与 40 张图片；超过上限会提示，纯文本仍受账号的 `maxBodyChars` 限制。

**外部图片默认阻止。** 点击「加载外部图片」只允许当前打开的邮件加载；打开另一封或重新打开后需要重新选择。加载可能向发件人透露阅读时间和网络地址。服务端只获取公开 HTTPS 图片，不附带邮箱凭据、浏览器 Cookie 或来源地址，拒绝私网地址和不安全重定向。网络、代理或服务器限制可能导致失败；可重试，或改用原邮箱客户端。不要为加载邮件图片关闭必要的 VPN 或安全设置。

遇到 VPN 的 Fake-IP（198.18/15）解析时，插件会通过 Cloudflare 的加密 DNS 确认真实公网地址，再固定连接到经过检查的目标；每次跳转也会重新检查。普通公网解析继续使用系统 DNS。只有下载当前已选择加载的外部图片或附件时才可能查询其域名，不发送完整链接、邮箱凭据或邮件正文；本地和内网保留域名不会送到公共解析器。若无法确认目标，仍会阻止下载并显示原因。个别图片服务器的拒绝连接或网络故障仍可能导致失败。

AgentMail 的 HTTPS / data 图片可显示；API 没有提供可匹配 Content-ID 时，CID 图会保留占位与原附件下载入口。POP3 仍需取得整封 MIME 邮件；IMAP 优先按正文和图片分段读取。

## 接续回复

1. 在原邮件中选择「回复到草稿」或「回复全部到草稿」。此时不会发送。
2. 在引用原文上方填写回复。普通较长邮件不再在 2,000 字处截断，引用上限为 20,000 字；超过时明确标注截断。
3. 保存，预览实际 To/Cc、账号、正文与附件，最后确认发送。

编辑和保存保留原邮件引用，发送时重新取得 `Message-ID` / `References`。IMAP 文件夹的 UIDVALIDITY 改变时会拒绝继续发送，防止回复到重新编号后的另一封邮件。收件人拒绝规则和发送确认继续生效。

## 移入废纸篓

此功能适用于 **IMAP**。在详情选择单封，或勾选当前页最多 20 封，点击「移入废纸篓」。

1. 确认框展示账号、原文件夹、目标与主题列表。优先识别服务器的 `\Trash`；没有识别到时，可明确选择已有文件夹，不自动创建或清空文件夹。
2. 取消不会修改邮件。确认有效期为 90 秒，账号或文件夹身份改变后需要重新确认。
3. 确认后执行有范围的移动，不执行全文件夹清空或永久删除。服务器须支持 MOVE 或 UIDPLUS；均不支持时拒绝操作。
4. 服务器完整返回目标 UID 与 UIDVALIDITY 时提供 **5 分钟内的一次撤销**。没有完整编号时，请用邮箱客户端移回原文件夹。

移动后连接中断时，结果可能不明：先刷新原文件夹和废纸篓核对，不要直接重复提交。恢复也会核对邮件身份。POP3 与 AgentMail 暂不提供本工作台的废纸篓功能，请在原邮箱客户端整理。

自动安装仍默认关闭；升级和重启由使用者选择。
