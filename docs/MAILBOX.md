# 阅读图文、接续回复与整理邮件

适用于 dsh-email 0.32.0。入口为 DSH 侧边栏「邮件 → 收发邮件」，中英文文案跟随宿主语言。

## 「信桌」与「三栏」双视图

「收发邮件」默认打开**「信桌」**实体书信分拣台，可随时通过顶部检索条右侧的 **「信桌 / 三栏」** 分段按钮 1 键切换：

- **信桌模式（默认）**：顶部紧凑条收拢账号切换、文件夹树下拉（附未读角标）、关键词搜索、「只看未读」、「本页有附件」与「待阅」计数；中央呈现 3 层堆叠航空信纸卡片，左滑（`←` / `J`）跳过下一封、右滑（`→` / `Enter`）展开信纸全文，点击「翻面看信封头」（`Space` / `F`）3D 翻转查看原始信封与服务器元数据，点击「展开信纸全文」进入居中沉浸信纸阅读并可「← 收拢回信桌」；底部操作坞提供上一封、跳过、翻面、展开、回复到草稿、已读/星标与移入废纸篓。
- **三栏模式（经典）**：完整保留左侧可折叠文件夹树、可拖拽宽度的邮件列表与右侧正文分栏，以及本页勾选批量移入废纸篓。

## 文件夹层级与未读标记

左侧文件夹按服务器返回的分隔符与父路径显示为可折叠的树：系统文件夹排在前面，自建文件夹按名称排列，子文件夹缩进显示在父文件夹下面。带子文件夹的行前面有展开/收起箭头，鼠标悬停文件夹可以看到完整路径；「管理文件夹」弹窗也按同样的层级缩进排序。

每个文件夹后面的数字是该文件夹自己的未读数，由 IMAP `STATUS UNSEEN` 读取（服务器支持 `LIST-STATUS` 时随 `LIST` 一次返回，否则逐个文件夹查询）。打开邮件、标记已读/未读后，当前文件夹的数字会立即更新；重新加载文件夹列表时以服务器为准。服务器无法报告 STATUS 时不显示数字，也不会伪造为 0。POP3 与 AgentMail 没有服务器未读计数，因此不显示该标记。

## 阅读图文

打开邮件后，工作台保留段落、列表、表格、链接和可识别的内嵌图片；可随时切换纯文本。邮件不会作为网页直接执行：脚本、表单、嵌入页面、事件属性和来源样式不会进入页面。

内嵌 CID 图片从当前邮件附件读取；PNG、JPEG、GIF、WebP 可显示，每张最多 2 MiB。SVG 等格式仍可作为附件下载。损坏或不支持的图片显示失败状态，可重试。图文结构最多处理 256 KiB HTML、32 层、5,000 个节点与 40 张图片；超过上限会提示，纯文本仍受账号的 `maxBodyChars` 限制。

**外部图片默认阻止。** 点击「加载外部图片」只允许当前打开的邮件加载；打开另一封或重新打开后需要重新选择。加载可能向发件人透露阅读时间和网络地址。服务端只获取公开 HTTPS 图片，不附带邮箱凭据、浏览器 Cookie 或来源地址，拒绝私网地址和不安全重定向。网络、代理或服务器限制可能导致失败；可重试，或改用原邮箱客户端。不要为加载邮件图片关闭必要的 VPN 或安全设置。

遇到 VPN 的 Fake-IP（198.18/15）解析时，插件会通过 Cloudflare 的加密 DNS 确认真实公网地址，再固定连接到经过检查的目标；每次跳转也会重新检查。普通公网解析继续使用系统 DNS。只有下载当前已选择加载的外部图片或附件时才可能查询其域名，不发送完整链接、邮箱凭据或邮件正文；本地和内网保留域名不会送到公共解析器。若无法确认目标，仍会阻止下载并显示原因。个别图片服务器的拒绝连接或网络故障仍可能导致失败。

AgentMail 的 HTTPS / data 图片可显示；API 没有提供可匹配 Content-ID 时，CID 图会保留占位与原附件下载入口。POP3 仍需取得整封 MIME 邮件；IMAP 优先按正文和图片分段读取。

## 接续回复

1. 在原邮件中选择「回复到草稿」或「回复全部到草稿」。此时不会发送。
2. 在引用原文上方填写回复。普通较长邮件不再在 2,000 字处截断，引用上限为 20,000 字；超过时明确标注截断。
3. 保存，预览实际 To/Cc、账号、正文与附件，最后确认发送。

编辑和保存保留原邮件引用，发送时重新取得 `Message-ID` / `References`。IMAP 文件夹的 UIDVALIDITY 改变时会拒绝继续发送，防止回复到重新编号后的另一封邮件。收件人拒绝规则和发送确认继续生效。

## 通讯录与收件人姓名

工作台新增「通讯录」页，数据只保存在本机 `~/.dsh/data/dsh-email/contacts-v2.sqlite3`（或 `DSH_HOME` 下同一路径），不会上传到任何服务器。旧版本留下的 `contacts-v1.json` 会在首次读写时一次性导入，原文件保留不动。

- **自动收集**：打开邮件列表或正文时，插件把来信人以及该邮件的 To/Cc 记入通讯录（自动跳过本机账号自己的地址）。同一个地址只保留一条，并记录出现次数与最近出现时间；自动条目最多 5000 条，超出时先淘汰出现次数最少、最久未出现、姓名最靠后的。
- **检索键**：每条联系人在写入时都会算出一条检索串，包含汉字姓名、全拼音节、拼音首字母、邮箱本地部分（工号）与部门拼音，例如 `张小明(技术二部)`、`100123@example.com` → `zhangxiaoming zxm jishuerbu jseb 100123`。姓氏多音字按姓氏读音索引（曾=zeng、单=shan、解=xie、查=zha、仇=qiu、区=ou、朴=piao、乐=yue、尉迟=yu chi、长孙=zhang sun），所以「曾伟」不会被索引成 `cengwei`。
- **手动添加**：在「通讯录」页填写姓名、邮箱与备注即可新增；编辑自动条目会把它转为手动条目，此后邮件头里的显示名不会再覆盖你填的姓名。
- **姓名渲染**：阅读视图的发件人、收件人、Cc，以及邮件列表的发件人列，都会优先显示你手动维护的姓名；没有手动条目时使用邮件头自己的显示名，最后才回退到自动收集到的姓名或邮箱地址。渲染格式为 `姓名 <邮箱>`。
- **安全边界**：姓名在写入前会去掉 `<`、`>`、引号、逗号、分号与控制字符，避免拼接邮件头时被注入；损坏的通讯录文件或数据库会报错并保留原数据，不会静默清空，也不会影响邮件列表与正文的读取。

## 发信时的收件人补全

「写邮件」的收件人（To）与抄送（Cc）输入框会根据当前输入的位置识别正在编辑的那一个地址，并从通讯录给出候选：

- 输入邮箱前缀（如 `ali`）或姓名片段即可筛选；候选优先级为精确地址、地址前缀、姓名前缀、拼音/首字母/工号前缀、片段包含，手动条目排在自动条目之前。因此输入 `张小`、`zxm`、`zhangxiaoming` 或工号 `100123` 都能找到同一位同事。
- 用 `↑` / `↓` 选择，`Enter` 或 `Tab` 填入；也可以直接点击候选项。完整输入一个已知邮箱后按 `Enter` / `Tab`，同样会把姓名补进地址。填入的是 `姓名 <邮箱>`，因此对方收到的是带姓名的地址，而不是裸邮箱。
- 补全只替换光标所在的那一个地址：`a@x.com, b` 中只会补全 `b`，不会动前面的收件人。`Esc` 关闭候选列表，也可以继续手动输入任何地址；候选缺失不会阻止发送。
- 草稿仍以逗号分隔的普通地址字符串保存，已有的收件人规则、禁止名单与发送前预览继续按同一套解析生效。

## 移入废纸篓

此功能适用于 **IMAP**。在详情选择单封，或勾选当前页最多 20 封，点击「移入废纸篓」。

1. 确认框展示账号、原文件夹、目标与主题列表。优先识别服务器的 `\Trash`；没有识别到时，可明确选择已有文件夹，不自动创建或清空文件夹。
2. 取消不会修改邮件。确认有效期为 90 秒，账号或文件夹身份改变后需要重新确认。
3. 确认后执行有范围的移动，不执行全文件夹清空或永久删除。服务器须支持 MOVE 或 UIDPLUS；均不支持时拒绝操作。
4. 服务器完整返回目标 UID 与 UIDVALIDITY 时提供 **5 分钟内的一次撤销**。没有完整编号时，请用邮箱客户端移回原文件夹。

移动后连接中断时，结果可能不明：先刷新原文件夹和废纸篓核对，不要直接重复提交。恢复也会核对邮件身份。POP3 与 AgentMail 暂不提供本工作台的废纸篓功能，请在原邮箱客户端整理。

自动安装仍默认关闭；升级和重启由使用者选择。
