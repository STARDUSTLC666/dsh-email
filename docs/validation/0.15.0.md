## 官方 Web 可见操作

使用独立 DSH_HOME 和只监听本机的合成 SMTP 服务。未使用真实模型或邮箱凭据，未向外部邮箱发送邮件。

- 新建、编辑 To/Cc/主题/正文、保存、重开和切换发件账号。
- 原生文件选择器上传，预览下载字节一致；取消预览不触发 SMTP。
- 关闭设置后恢复未保存编辑；冲突保留输入，显式选择已保存版本。
- 规则按账号保存，未保存切换提示、陌生 Cc 阻止跳过、全部匹配预览及账号隔离；修改规则后重新检查发送预览。
- 明确确认后提交一封完整邮件：发件显示名、全部 To/Cc、二次编辑正文和附件与实际 MIME 一致。
- 模拟 SMTP 收到 DATA 后断开：结果未确定，刷新不重发。另一次拒绝 Cc：回执明确列出接受与拒绝地址，不自动重发。
- 删除原草稿后，独立副本附件仍可下载；只操作合成草稿的上传副本。
- 390px 视口：工作区宽度与滚动宽度均为 330px，预览均为 328px；导航、表单、下载和确认可操作。检查英文工作台文案；浏览器错误日志为空。
- 无登录 cookie 访问新增真实 carrier 路由返回 401。

合成服务共记录 3 次 SMTP DATA：完整接受 1 次、回执丢失 1 次、Cc 拒绝 1 次。其余新建、编辑、规则检查、取消、冲突恢复和下载没有增加投递次数。
