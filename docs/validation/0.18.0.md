# 0.18.0 · AgentMail 与收发邮件工作台

日期：2026-10-21。Windows，官方 npm DSH **0.2.1-rc.2**；隔离 profile、合成邮箱和凭据，不使用用户真实邮箱或模型密钥。

## 已验证

- Windows / Node 24.16.0 下 **372 项测试通过，无失败、无跳过**。构建产物与源码同步，手写网页端 JavaScript 语法检查通过。

- 自动回归覆盖固定区域 API 与账号隔离、HTTP 错误脱敏、数字/字符串 UID、分页/相关性搜索、未读标签、取消不消耗提醒积压、直接跟随 API 游标、新邮件基线、附件大小/公网 HTTPS 限制、跨源请求拒绝、回复草稿持久化、禁止收件人和手动确认。
- 官方 DSH 宿主内安装同一生产应用装配，用依赖注入把 AgentMail 网络请求送到本机真实 HTTP 协议端点；普通邮箱连接本机真实 IMAP 协议端点。没有用前端假数据替代邮箱路由。
- 后台 Chrome 实际点击：收件箱、已发送、翻页、搜索、纯文本正文、已读/星标、附件下载、回复进入草稿、编辑保存、预览取消、核对确认发送。取消前后 HTTP POST 发送次数均为 0；确认后为 1，调用原 `message_id` 的 `/reply`，保留线程。
- IMAP 账号通过生产 EmailService / EmailPool 列表及正文读取；API/IMAP 切换不会串入迟到的其他账号结果。合成 503 错误、空文件夹与恢复操作可见。
- IMAP 回复草稿记录 UIDVALIDITY；提交前重新核对并提取 Message-ID/References。自动回归确认原线程头与已审核正文保留，邮箱重新编号时不提交 SMTP。
- 中英文、1440px 与 390px、浅色与深色检查；390px 设置弹窗 scrollWidth/clientWidth 均为 390，没有横向溢出。页面脚本无未捕获异常，邮件中的 `<script>` 按文字显示。
- 模拟附件 `quote.txt` 下载内容为 `quote`；真实公网 DNS/HTTPS 防护另有自动回归。

## 未验证与限制

- 无真实 AgentMail 账号/API Key，未验证真实服务权限、套餐、投递、远端签名附件或实际收件；模拟回执不能证明真实投递。
- 本轮是官方 Web 宿主的浏览器操作验收，不宣称完成原生桌面窗口、系统文件对话框或 18 个插件逐项验收。
- 没有重新登录用户真实普通邮箱，也没有向任何真实收件人发信。生产网络出口、代理/VPN 与邮件服务差异需要相应环境复核。

临时协议服务、合成邮箱、测试下载、隔离进程与 profile 在验收和发布检查后清理；源码回归用例保留。
