# 0.16.1：会话附件与发信策略说明

日期：2026-10-08。Windows / Node 24.16.0，官方 DSH 0.2.1-alpha.1 的隔离网页版。

## 修复与回归

- 在启动目录和会话工作区分别放置同名 `report.txt`，内容不同。`email_send` 实际文件读取和 `email_draft` 的附件预览均取得会话文件内容，启动目录原文件保持不变。
- 绝对附件路径保持精确；没有会话时保留启动目录回退。三个新增回归通过，既有收件人拒绝、确认、取消、大小限制与草稿快照规则保持。
- 中英文确认开关不再笼统声称 Full Access 必然拒绝：主动保存且启用的可信规则只跳过 `email_send` 插件确认，宿主权限仍生效；禁止规则始终优先。

## 实际界面操作

通过明确标记的脚本工具选择适配器，在聊天中用相对路径创建草稿；进入「设置 → 邮件 → 草稿」，检查发送预览，下载并核对附件，勾选核对框后向本机合成 SMTP 服务确认发送。服务器仅接收一封邮件，附件内容与当前会话文件一致；已发送草稿不再提供再次发送按钮。

切换官方界面语言后核对英文账号页，确认说明、草稿入口和禁止规则提示均显示英文。1280×720 截图中相关说明可读，浏览器控制台无 error / warn，页面无空白或错误覆盖层。

## 范围

未操作用户原生 Electron 窗口，未使用真实邮箱凭据，未向外部邮箱发送测试邮件。脚本选工具验收不证明模型自主选工具能力；UI 的 SMTP 回执不代表外部收件箱送达。附件仅改变路径基准，不增加文件访问权限或关闭确认。

开放反馈 [Email #19](https://github.com/STARDUSTLC666/dsh-email/issues/19) 的名单控件、匹配预览和显式开关均已具备；仍保留主动启用、域名精确匹配及宿主权限边界，咨询没有被自动关闭。
