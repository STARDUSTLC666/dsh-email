# 0.16.3 · DSH alpha.5 网页验收

宿主为公开 npm `@deepseek-ai/dsh@0.2.1-alpha.5`，Windows Node 24，系统 Chrome 无头浏览器。使用独立 profile、合成邮箱与只监听回环地址的 SMTP 服务。

- 347 项 Windows 自动测试通过，包含配置错误通过凭据脱敏后仍保留服务商选择的回归。真实 JWT、XOAUTH2 字符串和密码的脱敏测试继续通过。
- 未配置账号时可以保存本地草稿，发送预览明确报出缺失配置；服务商名称可以正常阅读。
- 实际点击/输入完成新草稿、账号选择、To、主题、正文、附件上传、发送预览、勾选核对与明确提交。
- 本机 SMTP 接收到唯一一次提交及附件；已发送草稿没有再次发送入口，复制得到独立未发送草稿。SMTP 回执不等于投递到真实收件箱。

未连接真实 IMAP、SMTP 或 OAuth 租户，未操作桌面原生窗口。
