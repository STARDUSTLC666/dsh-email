# Email 0.22.0 验收范围

日期：2026-11-05。对应 #34（整理历史邮件）、#36（原文回复与图片）。

- Windows / Node 24：完整测试及构建、发布包内容检查；新增受控 IMAP/SMTP 协议回归测试。
- 官方 DSH npm 运行时：0.2.1-rc.5（latest）、0.2.2-alpha.3、0.2.2-rc.1（next）。独立隔离 profile，不使用真实邮箱或现有桌面配置。
- 实际 Chrome 浏览器操作：每版分别验收中文 / 深色 / 1440px，英文 / 浅色 / 390px。无可用专用 Browser 插件，使用 Playwright 控制后台 Chrome；未切换使用者前台窗口。
- 图文：真实 MIME 分段读取、CID 附件图片实际解码、表格和纯文本切换；未选择加载前不发出外部图片请求；外部图片连接失败及重试；脚本未执行；无页面横向溢出。
- 回复：超过 2,000 字的原文结束标记保留，浏览器编辑保存草稿；受控 SMTP 接收实际发送的 MIME，核对 Message-ID 关联、References 与原文尾部。
- 整理：取消确认后服务器邮件数量不变；当前页批量移入废纸篓，随后通过目标 UID 映射撤销；过期、账号改变、UIDVALIDITY 改变、缺失目标、部分邮件消失均有拒绝或恢复核对路径。
- 图片成功下载、格式/大小限制、公开地址约束以及账号配置在异步加载中变化另有自动化回归；外部成功字节由受控下载器提供，不能视为真实互联网图片源验收。

未验收：真实第三方邮箱的移动/撤销、真实互联网图片成功加载、真实收件人发送，以及 Electron 原生窗口操作。浏览器与协议服务通过不等于这些项目通过。POP3 / AgentMail 废纸篓与 AgentMail 未提供 Content-ID 的图片仍有明确功能边界，见[操作说明](MAILBOX.md)。

GitHub CI、npm 发布与全新官方 CLI 安装结果另行核验；最终记录保存在维护工作区的本批报告中。临时 profile、测试账号与构建缓存不进入发布包；回归测试作为维护代码保留。
